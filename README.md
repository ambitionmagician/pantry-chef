# Pantry Chef — cook from what you already have

A single-file installable PWA (index.html inline CSS/JS, manifest.json, sw.js): the user checks off ingredients they have from a searchable pantry list (plus free-text additions); the app matches them against a built-in base of at least 40 simple recipes (each with ingredients, steps, time, servings), ranks recipes by fewest missing ingredients, shows the top matches with the missing items as a shopping list, and scales quantities by servings. Pantry persists in localStorage. Fully offline, no external requests. Deliverable: complete index.html, manifest.json, sw.js.
